## Minecraft plugins, made simple.

**Dynasty Plugins** is the home of **DyPlugin**, founded by [Claw / cl5w](https://github.com/cl5w) in Türkiye. We build Minecraft server plugins around straightforward commands, focused features and configurable behavior.

Protect a survival world, help players explore, give them a way home and connect the server to Discord. Start with the plugins you need and add their optional integrations as your community grows.

## Our plugins

| Plugin | What it brings to your server | Explore |
| --- | --- | --- |
| **[DyClaim](https://github.com/DyPlugin/DyClaim)** | Chunk claiming, land protection, trust and ownership management, with optional economy features. | [Docs](https://github.com/DyPlugin/DyClaim#readme) · [Downloads](https://github.com/DyPlugin/DyClaim/releases) |
| **[DyRTP](https://github.com/DyPlugin/DyRTP)** | Random teleportation with destination safety checks, world profiles, biome selection and optional protection hooks. | [Docs](https://github.com/DyPlugin/DyRTP#readme) · [Downloads](https://github.com/DyPlugin/DyRTP/releases) |
| **[DyDiscord](https://github.com/DyPlugin/DyDiscord)** | Account linking, two-way chat, roles and server updates through your own Discord bot. | [Docs](https://github.com/DyPlugin/DyDiscord#readme) · [Downloads](https://github.com/DyPlugin/DyDiscord/releases) |
| **[DyHomes](https://github.com/DyPlugin/DyHomes)** | Named homes, warps and spawn, with rank limits, safe teleports, DyClaim trust integration and Folia support. | [Docs](https://github.com/DyPlugin/DyHomes#readme) · [Downloads](https://github.com/DyPlugin/DyHomes/releases) |

Compatibility, dependencies, languages and release status are documented separately for each plugin. Check the project's README and release notes before choosing a build.

## Better together

- **Protect and explore:** DyRTP can respect DyClaim land protection when choosing destinations.
- **Homes that respect trust:** DyHomes checks the relevant DyClaim rights when players set and use homes inside claims.
- **Keep your community informed:** DyDiscord can send DyClaim and DyRTP events to a Discord channel you choose.
- **Choose your integrations:** Supported projects offer optional hooks for tools such as Vault and PlaceholderAPI. Each repository explains what is supported.

## Get started

1. Choose a plugin above and read its requirements, including the Minecraft platform and Java version.
2. Download the appropriate build from the project's releases or [Modrinth](https://modrinth.com/organization/dyplugin).
3. Stop your server, back up existing plugin data and install the selected JAR in `plugins/`.
4. Start the server, configure the generated files and follow that plugin's setup guide.

You can find the full collection at **[dynastyplugins.com](https://dynastyplugins.com)**.

## Support and contributions

**Need help?** Join [DyHub on Discord](https://discord.gg/dyhub). For a reproducible bug or a feature request, open an issue in the affected plugin's repository:

[DyClaim issues](https://github.com/DyPlugin/DyClaim/issues) · [DyRTP issues](https://github.com/DyPlugin/DyRTP/issues) · [DyDiscord issues](https://github.com/DyPlugin/DyDiscord/issues) · [DyHomes issues](https://github.com/DyPlugin/DyHomes/issues)

Include your plugin version, server software, Minecraft and Java versions, reproduction steps and relevant logs. Remove tokens, passwords and other private information before posting configuration files.

**Want to contribute?** Bug reports, documentation improvements, translations and focused pull requests are welcome. Read the project's README, build instructions and license first; for a larger change, describe the idea in an issue before implementing it.
